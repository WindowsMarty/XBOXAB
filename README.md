# XBOXAB
将XBOX主机官方动态壁纸转换为视频的macOS应用

使用 Swift 开发，支持浏览官方壁纸、自动下载，并在本地渲染和导出视频。

## 功能

- 浏览官方壁纸
- 自动下载、解压、渲染和转换
- 主义：由于动态视频获取需要用户XBL Token，应用未增加在线更新壁纸列表功能

## 视频输出

- 分辨率：1920 × 1080
- 帧率：60fps
- 格式：MP4
- 编码：HEVC Main10
- 平均码率目标：100 Mbps

## 使用

1. 启动应用，浏览或筛选官方壁纸。
2. 点击壁纸，等待下载和转换完成。
3. 转换完成后，会使用默认视频打开方式打开mp4文件
